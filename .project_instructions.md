# Proyecto: Portafolio Arquitectónico — Casa Unifamiliar 2 Pisos

## Contexto
- Proyecto académico del estudiante **Emanuel Ramírez López**
- Institución: **Colegio Marino Gómez Estrada**, Aguadas, Caldas
- Programa SENA: Dibujo Digital de Proyectos de Arquitectura e Ingeniería
- Ficha: 3160461
- El proyecto arquitectónico es una **casa unifamiliar de 2 pisos** (no el edificio del colegio)

## Paleta de colores (tokens de marca)
- Navy: #061b49 (primary)
- Red: #ee2637 (accent)
- Blue: #1c70db (links, interactive)
- Pale blue: #eaf4ff
- Paper: #f8fbff (background)
- Line: #a9c9f6

## Tipografía
- Headings: Archivo (black, 900 weight, tight tracking)
- Body: Inter
- Handwritten quotes: Nanum Pen Script

## Estructura (SPA single-page)
- 6 secciones: Inicio, Maqueta, Planos, Renderizado, Video 3D, Proceso
- Navegación: state-driven section switching (no routing)
- Footer: estilo "plano técnico" con celdas de info

## Características implementadas
- Dark mode (next-themes, persiste en localStorage)
- Animaciones: Framer Motion (page transitions, staggered cards, scroll reveals)
- Parallax hero, floating particles, typewriter effect, gradient mesh
- Lightbox modal con zoom (rueda + botones), pan con drag, navegación teclado y swipe
- Search con teclado y highlight
- Video player simulado con progress bar y chapters
- Toast notifications
- Back-to-top button
- Scroll progress bar (red line en top)
- Header sticky glass effect
- Responsive: mobile, tablet, desktop
- Images: MediaImage component with graceful skeleton fallback

## Imágenes
- Las imágenes referencian `/assets/references/<name>.jpg`
- El usuario debe colocar sus imágenes reales en `public/assets/references/`
- El componente MediaImage muestra un skeleton animado si la imagen no existe
